FITUR UTAMA

Semua yang dibutuhkan untuk mengelola pembayaran.

Mulai dari pemantauan invoice hingga alat integrasi developer, disusun dalam satu pengalaman merchant yang konsisten.

▤

Manajemen Invoice

Buat dan pantau invoice, lihat nominal, metode pembayaran, batas waktu, serta status transaksi dari dashboard.

⌁

Integrasi API & Webhook

Siapkan koneksi server-to-server dan endpoint notifikasi agar aplikasi merchant dapat terhubung dengan SkieePay.

◈

Kontrol Merchant

Kelola API Key, endpoint webhook, dan akses dashboard melalui area merchant yang dibatasi untuk admin.

UNTUK DEVELOPER

Hubungkan aplikasi melalui API.

Gunakan kredensial server-side dan endpoint SkieePay untuk mengintegrasikan proses pembuatan invoice. Jangan pernah menaruh secret key di browser.

API service memeriksa…
POST /v1/invoices
Content-Type: application/json
X-SkieePay-Key: YOUR_SERVER_KEY

{
  "amount": 25000,
  "payment_method": "qris",
  "expires_minutes": 30
}
