GoPay Merchant

Hubungkan akun GoPay Merchant SKIEESTORE melalui verifikasi OTP, lalu kelola sesi dan periksa mutasi dari backend SkieePay.

Integrasi nonresmi. Koneksi ini menggunakan endpoint GoBiz yang tidak dipublikasikan sebagai API merchant umum. Perubahan sistem atau pencabutan sesi dapat memutus koneksi. OTP dimasukkan langsung di halaman ini—jangan kirim OTP, password, atau token ke chat.

1. Hubungkan akun

Masukkan nomor yang terdaftar di GoPay Merchant. Kode OTP akan dikirim oleh GoBiz.

2. Status koneksi

Sesi disimpan terenkripsi di Supabase Vault dan diperbarui otomatis menjelang kedaluwarsa jika refresh token masih berlaku.
